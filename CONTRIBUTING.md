# Участие в проекте

Сообщения об ошибках и предложения принимаются в [Issues](https://github.com/MrSamurai4/Golyahki/issues). Укажите версию Golyahki, Windows, действия для воспроизведения и ожидаемый результат. Используйте вымышленные фразы и небольшие примеры словарей.

Для изменений создайте ветку, выполните [настройку окружения](docs/SETUP.md) и запустите `python -m pytest -q`. Для изменений захвата и интерфейса проверьте поведение на Windows; для изменений упаковки — готовые EXE через `python -m scripts.check_build`.

Перед отправкой выполните `python -m scripts.audit_release --tracked` после добавления файлов в Git. Не добавляйте ключи, `.env`, базы SQLite, экспорты личных слов, Anki-коллекции, рабочие скриншоты, журналы и резервные копии. Новые тесты должны работать без реального Gemini и личной коллекции Anki.

Опишите проблему, решение и проверку в pull request. Вклад в исходники предоставляется под лицензией MIT проекта; сохраняйте атрибуцию сторонних материалов.
