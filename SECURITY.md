# Безопасность

Не прикладывайте API-ключи или личные базы к публичным Issues. Случайно раскрытый ключ нужно отозвать у провайдера.

О проблемах безопасности сообщайте через [private vulnerability reporting](https://github.com/MrSamurai4/Golyahki/security/advisories/new). Если форма недоступна, создайте Issue с просьбой предоставить приватный канал без деталей уязвимости, ключей и пользовательских данных.

В проверках используйте синтетические данные и временную базу. Ключ Gemini хранится в Windows Credential Manager. Приложение не шифрует локальную SQLite-базу. Подробнее — в [описании данных](docs/PRIVACY.md).
