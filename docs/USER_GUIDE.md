# Руководство Golyahki

## Словари и поиск

На странице «Словари» импортируйте Yomitan v3 ZIP или JSON формата Golyahki. Для проверки есть `examples/custom-dictionary.json` со словом `experience`; в программе также есть небольшая встроенная статья `nah`. Полного английско-русского словаря в выпуске нет. Импортируйте словари, которыми имеете право пользоваться, сохраняя сведения об источнике и лицензии.

Поиск принимает слово, фразу или предложение. Формы находятся, если соответствующие связи есть в словаре. Кнопка **Show translation** раскрывает переводы; примеры раскрываются отдельно. Если данных нет, программа не придумывает их как словарные: можно запросить Gemini.

## Захват экрана

В настройках выберите окно или монитор. Для игры удобнее оконный режим без рамки. Защищённые видео, эксклюзивный полноэкранный режим и отдельные приложения могут не допускать захват.

| Действие | По умолчанию |
| --- | --- |
| Распознать выбранный источник | `Alt+Q` |
| Открыть слово | Левый клик |
| Выделить диапазон после первого слова | `Shift+клик` по последнему слову |
| Добавить или убрать отдельное слово | `Ctrl+клик` |
| Добавить диапазон | `Ctrl+Shift+клик` |
| Закрыть карточку и оверлей | `Esc` или клик по пустому месту |

Карточку можно перемещать за заголовок. OCR анализирует один кадр: если текст на экране изменился, повторите захват. Движок **Auto** предпочитает WindowsOCR; при его недоступности использует PaddleOCR. В настройках можно выбрать движок явно. Первый запуск Paddle медленнее последующих.

## Gemini

Введите свой API-ключ в настройках и выберите доступную модель. Explain запрашивает значение и примеры, Context translator — перевод контекста. Без интернета остаются доступны локальные словари и ранее полученные результаты. Ошибки и квота показываются в интерфейсе. При ошибке квоты программа может пробовать резервную модель `gemini-3.5-flash-lite`; её доступность также зависит от аккаунта Google.

Плюс в карточке запрашивает недостающие объяснения для учебной записи. Если запрос не завершился, откройте **Мои слова → Черновики** и нажмите **Повторить добавление**. Отсутствие ключа тоже оставляет запись в черновиках.

## Anki

Установите AnkiConnect (код `2055492159`) в Anki Desktop, перезапустите Anki и оставьте её открытой. Стандартное подключение — `http://127.0.0.1:8765`. В Golyahki нажмите **Подключить Anki** и выберите уже созданную колоду. Режим **Только Dictionary** сохраняет записи локально.

Передаются все переводы и примеры найденных словарных статей, а не только выбранное значение. Повторное добавление того же слова с тем же контекстом не создаёт дубликат; новый контекст может создать отдельную заметку. Ошибка Anki оставляет запись для повторной отправки.

Варианты: слово → перевод, перевод → слово, предложение с пропуском. Для последнего нужен подходящий контекст. Конструктор меняет порядок, видимость и оформление полей. Команды применения оформления обновляют шаблоны существующих типов карточек Anki: сделайте резервную копию коллекции перед изменением своих шаблонов.

## Резервная копия и удаление

Экспорт на странице личных слов сохраняет учебные записи, но не подключённые словари и настройки. Для полной копии закройте приложение через трей и скопируйте `%LOCALAPPDATA%\GOlyah`. API-ключ переносится отдельно — введите его на новом компьютере самостоятельно.

Удаление папки программы не удаляет вашу базу. Чтобы удалить личные данные, закройте программу и удалите папку данных. Ключ удаляется кнопкой в настройках или из Windows Credential Manager: сервис `GOlyah.Gemini`, пользователь `api-key`.
