# Данные и приватность

## Что включено в публичный выпуск

Код, ресурсы интерфейса, демонстрационный словарь и тестовые фразы, зависимости и локальные OCR-модели. Ключ автора, его базы, подключённые словари, коллекция Anki, история переводов, рабочие снимки экрана, резервные копии и внутренние отчёты не включаются. История публичного репозитория начинается с подготовленной версии.

## Где находятся ваши данные

| Данные | Место хранения |
| --- | --- |
| Gemini API-ключ | Windows Credential Manager, сервис `GOlyah.Gemini`, имя `api-key` |
| Личные слова, контекст, словари, настройки, ответы Gemini | `%LOCALAPPDATA%\GOlyah\golyah.sqlite` |
| Кеш предпросмотра Anki | `%LOCALAPPDATA%\GOlyah\webview` |
| Экспорт слов | Файл, который вы сами выбрали при экспорте |
| Карточки, отправленные в Anki | Ваша коллекция Anki |

Экспорт слов не содержит API-ключ. Он содержит ваши слова, предложения, объяснения и примеры — проверяйте его перед передачей другим людям. База не зашифрована приложением: защищайте учётную запись Windows и резервные копии.

## Сетевые обращения

**Gemini:** запросы Explain, Context translator, получение моделей и подготовка недостающих данных при сохранении могут обращаться к Google. Отправляются текст выбранного слова/фразы, предложение, позиции выделения и краткие сведения из выбранного словарного значения. Изображение экрана не отправляется. Условия обработки и тарифы определяются вашим сервисом Google.

**AnkiConnect:** данные выбранных учебных записей передаются локальному API Anki. Если в Anki включена синхронизация, её дальнейшую работу определяют настройки Anki. Golyahki не подключается к AnkiWeb напрямую.

**OCR:** WindowsOCR и PaddleOCR работают локально. В готовый ZIP включены модели Paddle. При первом использовании Paddle из исходников библиотека скачивает модели. Установка зависимостей и компонентов Windows тоже требует загрузок.

У приложения нет собственного сервера, учётной записи Golyahki, встроенной аналитики и автоматической отправки отчётов об ошибках.

## Снимки и режимы разработчика

Обычный захват хранит кадр в оперативной памяти, передавая его OCR-процессу через shared memory. Параметр `--smoke` специально сохраняет снимок интерфейса по указанному пути; не публикуйте такой снимок с личными данными. `--data-dir` изолирует базу, но не создаёт отдельное хранилище ключей Windows. Для публичных снимков используйте синтетические примеры и не открывайте страницу с названиями своих окон.

## Если ключ случайно опубликован

Отзовите его у провайдера и создайте новый. Удаление строки или файла из последнего коммита не удаляет секрет из прошлой истории. Не вставляйте ключи в Issues, скриншоты, логи или примеры конфигурации. Программа настраивается через интерфейс; `.env` ей не требуется.
