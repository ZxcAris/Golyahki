# Проверки выпуска 1.0.0

Проверено 11 октября 2026 года. Проверки используют учебные фразы, временные базы и подменённые ответы API; личная коллекция Anki и платные запросы Gemini не нужны.

## Исходники

- 365 тестов прошли на чистом Windows runner GitHub после установки проекта и зависимостей. [Успешный запуск](https://github.com/MrSamurai4/Golyahki/actions/runs/38164072327).
- 13 проверок, которым нужны настоящий интерактивный рабочий стол, нативный ввод или WebView2, проверены локально. В облачном CI они не выполняются.
- После исправления локали Windows отдельно прошли 108 проверок Gemini, обработки квот, OCR-коррекции и защиты публикации.
- Локальные относительные ссылки документации проверены. Скриншот README создан с демонстрационным словарём и отдельной базой.

## Готовая программа

- Запуск EXE с отдельной временной базой и без Python в PATH.
- WindowsOCR и PaddleOCR распознали контролируемое изображение. Модели Paddle берутся из сборки, кадр передаётся через общую память.
- Открыты поиск, оформление, конструктор Anki, настройки и карточка OCR; все процессы завершились с кодом 0.
- Нативный WebView2-предпросмотр отдельно проверен с тестовыми словами. Он является дочерним нативным окном и не попадает в обычный QML-снимок `grabWindow`.

## Проверка публикации

- Новая история Git содержит только публичные исходники. Коммиты используют GitHub noreply-адрес.
- Gitleaks проверяет Git-историю и автоматически запускается на GitHub. В GitHub включены secret scanning, push protection и приватные сообщения об уязвимостях.
- Отдельный аудит проверяет типы файлов, форматы ключей, экспорты учебных записей, пути профилей, метаданные установок и код приложения внутри EXE.
- Срабатывания Gitleaks в неизменённых исходниках сторонних OpenCV/PaddleX были проверены: они относятся к именам типов и переменных, а не к учётным данным. Исключения не применяются к проверке исходников Golyahki.
- Упаковщик проверяет папку, CRC архива, повторно проверяет распакованное содержимое и создаёт SHA-256 для скачивания.

Проверки отражают указанное окружение. Они не заменяют проверку на всех конфигурациях Windows, играх и провайдерах; ограничения перечислены в README и руководстве.
