# Частые проблемы

**Программа не запускается.** Убедитесь, что ZIP полностью распакован, а `_internal` и оба EXE находятся в одной папке. Поддерживаемая платформа выпуска — Windows 11 x64. Если Windows сообщает об отсутствующей библиотеке MSVC, установите [Microsoft Visual C++ Redistributable x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).

**Windows показывает неизвестного издателя.** Выпуск не подписан цифровым сертификатом. Проверьте, что архив скачан из `MrSamurai4/Golyahki`, и сравните контрольную сумму. Не отключайте антивирус ради запуска неизвестного файла.

**Ничего не находится в поиске.** В выпуске нет полного словаря. Импортируйте свой Yomitan v3 ZIP или учебный `examples/custom-dictionary.json`, затем найдите `experience`.

**Не работает Alt+Q.** Выберите нужный источник в настройках и попробуйте кнопку захвата. Горячая клавиша может быть занята другой программой. Для игры попробуйте оконный режим без рамки.

**WindowsOCR недоступен.** Добавьте английский язык и компонент OCR в настройках языков Windows либо выберите PaddleOCR. Его модели уже включены в ZIP. Первый захват может занять больше времени.

**Ошибка Gemini или квоты.** Проверьте свой ключ, интернет, доступные модели и лимиты проекта Google. По умолчанию приложение использует `gemini-2.5-flash`; название модели можно изменить. Квоты не задаются Golyahki. Повторите запрос после устранения причины.

**Слово осталось в черновиках.** Для полной записи нужны объяснения Gemini и, если выбрана колода, доступная Anki. Исправьте причину ошибки и нажмите **Повторить добавление**.

**Anki не подключается.** Откройте Anki Desktop, проверьте установку AnkiConnect и перезапустите Anki. Стандартный адрес — `127.0.0.1:8765`. Убедитесь, что выбрана существующая колода. Произвольные конфигурации AnkiConnect с дополнительной API-аутентификацией в интерфейсе Golyahki не настраиваются.

**Пустой предпросмотр карточки.** Установите или восстановите [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) и перезапустите приложение.

**После закрытия окна приложение осталось запущено.** Это штатное поведение: Golyahki остаётся в системном трее. Выберите **Выйти** в его меню для полного завершения.

Если проблема осталась, создайте [Issue](https://github.com/MrSamurai4/Golyahki/issues/new/choose) с версией Windows и программы, шагами воспроизведения и текстом ошибки. Уберите личный текст, ключи, пути пользователя и названия окон со снимков.
